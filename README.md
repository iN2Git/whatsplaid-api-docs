# Whatsplaid API

Official developer documentation for the Whatsplaid WhatsApp automation platform.

## Documentation

Access the interactive Swagger documentation:

https://api.whatsplaid.com/docs/

The documentation includes:

- Whatsplaid Public API
- Custom Data Connector Contract
- Outgoing Webhooks

## Features

- Contact and lead management
- WhatsApp messaging
- Conversations and message history
- Human handoff
- Tags and custom fields
- Ecommerce integrations
- Custom product and order data connectors
- Outgoing lead capture webhooks

## Authentication

The Whatsplaid Public API uses Bearer Token authentication.

Base URL:

https://api.whatsplaid.com/v1

Authentication requirements for custom data connectors are described in their dedicated specification.
